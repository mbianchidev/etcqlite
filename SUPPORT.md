# Support

Start with [installation](docs/installation.md),
[configuration and logging](docs/logging.md),
[troubleshooting](docs/troubleshooting.md), and the [docs index](docs/README.md).

For non-security bugs or proposals, search existing
[issues](https://github.com/mbianchidev/etcqlite/issues), then use the
[issue chooser](https://github.com/mbianchidev/etcqlite/issues/new/choose).
Provide the commit/version, OS/architecture, exact command and synthetic
reproduction. This private experimental project has no support SLA, community
chat, paid support or promised response time.

Security reports use [SECURITY.md](SECURITY.md); conduct reports use the
[Code of Conduct](CODE_OF_CONDUCT.md). Do not attach real stores, snapshots,
secrets or customer logs to an issue.
